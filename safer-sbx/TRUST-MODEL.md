# safer-sbx 信任模型与剩余风险

## 明确声明

**safer-sbx 不是“完全安全”的方案。** 它只是相对仓库内大型一键脚本更窄、更可审查的安装路径。

## 你在信任什么

1. **本工具包源码**（`safer-sbx/` 目录）——请自行阅读后使用。
2. **钉死的官方 sing-box 发布资产**（GitHub `SagerNet/sing-box` Releases）。
3. **钉死文件中的 SHA-256**——这些摘要与二进制来自**同一 GitHub 发布通道**。若该通道被攻破，攻击者可以同时替换二进制与摘要。
4. **你的运营商配置**（Reality 目标域名、端口、服务器地址）。
5. **主机完整性**（已有 rootkit、被共享的 VPS 模板、失窃的 SSH 密钥不在本工具防御范围）。
6. **网络与 IP 环境**（封锁、劫持、错误路由会导致可用性变化，不是安装器能保证的）。

## 本工具做什么

- 拒绝不支持的 OS/架构（明确 Debian/Ubuntu + systemd + amd64/arm64）。
- 使用 HTTPS 下载钉死 URL；**禁止** `--insecure` / `curl|bash` 管道安装模型。
- SHA-256 **失败即停止**（fail-closed）。
- 解压前检查归档路径（拒绝绝对路径与 `..`）。
- 校验后再调用二进制生成密钥 / `check` 配置。
- 凭证本地生成；权限收紧；不向标准输出打印机密。
- systemd 最小能力与部分沙箱指令；不改防火墙/DNS/sysctl/SSH。
- 默认不接管无关 sing-box；卸载只删清单文件。

## 本工具不声称什么

- **不声称**已完成第三方代码审计或二进制形式化验证。
- **不声称**独立于发布通道的签名验证（当前输入未实现/未宣称）。
- **不声称** Reality 对任意目标域名永远可用。
- **不声称**可抵御主机已被攻破后的攻击。
- **不声称**自动跟踪官方最新版更安全（相反：刻意钉死，需人工更新钉死文件）。

## 建议

- 安装前备份 VPS；在快照上试验。
- 审阅 `operator.env` 与生成的配置路径权限。
- 客户端文件仅本机查阅，勿提交到 Git/聊天。
- 定期人工核对 `pinning/sing-box.env` 与官方 Release。
